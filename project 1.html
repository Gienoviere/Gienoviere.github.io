Running into madness

This game was made as a solo project, inspired by Subway Surfers and Doctor Strange. I built it in Unity in about one week, creating an endlessly generating map using C#. I used some assets and a tutorial, but added my own terrain design. The project was a success, though it needs a few tweaks.
